# Chirayu Kamble Portfolio

Open `index.html` in Visual Studio Code, then use the **Live Server** extension to preview it.

## Run locally

1. Open this folder in VS Code.
2. Install the extension **Live Server** by Ritwick Dey.
3. Right-click `index.html` and choose **Open with Live Server**.

## Publish with GitHub Pages

1. Create a GitHub repository named `chirayu-portfolio`.
2. Upload everything inside this folder.
3. Open the repository's **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/root`, then save.
5. GitHub will give you a public URL such as `https://yourusername.github.io/chirayu-portfolio/`.

Replace any image in `assets/work` with a redacted, higher-resolution version when available. Keep the filename the same so the page updates automatically.
